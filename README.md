# ChatGPT Skin Studio

## 项目简介

ChatGPT Skin Studio 是面向 ChatGPT Windows 桌面客户端的换肤工具。它为现有客户端添加自定义壁纸、透明界面和字体对比度适配，同时保持聊天、设置、模型切换和窗口操作等原生使用流程。

项目支持设置官方界面恢复、主题状态持久化，以及浅色和深色壁纸下的文字可读性处理。

## 界面效果

### 设置页与导航

设置主区域、设置卡片和左侧导航使用分层半透明面板，使背景融入界面，同时保持控件边界和文字清晰。

![ChatGPT Skin Studio 设置页半透明效果](docs/images/chatgpt-skin-studio-settings.png)

### 深色背景可读性

程序会根据壁纸明暗自动选择文字颜色：亮色背景显示深色文字，暗色背景显示浅色文字。会话正文、侧栏、模型菜单、设置页和弹窗使用同一套对比度规则。

![ChatGPT Skin Studio 暗色背景下的浅色文字效果](docs/images/chatgpt-skin-studio-dark-reading.png)

## 核心效果

| 效果 | 说明 |
|:--|:--|
| 自适应文字对比度 | 根据背景明暗选择深色或浅色文字，避免低对比度文字影响阅读。 |
| 分层透明面板 | 设置页、卡片、导航与常规浮层使用透明背景，保留壁纸层次。 |
| 浮动菜单可读性 | 个人菜单覆盖在会话列表上时使用高遮挡背景，避免菜单与后方标题重叠。 |
| 最大化窗口适配 | 修正最大化状态下标题区域和更多操作按钮的异常底色。 |
| 流畅交互 | 减少高频样式重算与无效界面扫描，改善翻阅会话记录和切换模型时的响应。 |
| 主题持久化与恢复 | 换肤后可退出 Skin Studio；恢复官方界面时回到 ChatGPT 原有配色。 |
